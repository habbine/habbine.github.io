Preview · Research toolBrain–Network Correspondence Atlas

Twelve proposed correspondences between human brain structures and the components of artificial neural networks. The anatomy is measured from published probabilistic atlases in MNI152 space, not drawn. Each correspondence holds only if the system compared has particular properties: change the configuration and the map changes with it.
